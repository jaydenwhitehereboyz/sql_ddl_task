# sql_ddl_task
# Сравнение схем двух БД PostgreSQL

## Подготовка

1. Создать базы: `00_create_dbs.sql`.
   Каждую команду выполнять отдельным запросом.
2. Создать таблицы:
   - `00_setup_left.sql` — в базе `schema_compare_left` (там же создаётся расширение `dblink`);
   - `00_setup_right.sql` — в базе `schema_compare_right`.

## Запуск

Все запросы выполняются в базе `schema_compare_left`.

Во всех вызовах `dblink` подставьте свои данные (без кавычек вокруг значений):

```sql
dblink('dbname=schema_compare_right user=ВАШЕ_ИМЯ_ПОЛЬЗОВАТЕЛЯ password=ВАШ_ПАРОЛЬ', ...)
```

**`task_1.sql`** — два запроса:
- перечень пересекающихся таблиц, которые есть в обеих БД
- различия в полях этих таблиц (тип, длина/точность, NULL, комментарий) — пункты 2–3 задания.

**`task_2.sql`** — генерирует DDL-команды, приводящие правые таблицы к левым.
Запрос ничего не меняет сам: результат (столбец `ddl`) нужно скопировать и выполнить в `schema_compare_right` в порядке шагов:
1. добавление отсутствующих полей;
2. изменение типов;
3. NOT NULL;
4. комментарии.

## Допущения и ограничения

- Эталон — левая БД.
- Сравниваются только таблицы, которые есть в обеих БД.
- Поля, которые есть только справа, не удаляются.
- `ALTER COLUMN ... TYPE ... USING` может не выполниться, если данные несовместимы с новым типом.
